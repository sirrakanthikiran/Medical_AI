How FHIR standardizes hospital data

The same blood pressure reading from three hospitals collapses into one resource shape.

1Fixed resource types

~140 building blocks (Patient, Observation, Condition...). Every lab result has the same shape, in every hospital.

2International medical codes

LOINC (labs), SNOMED-CT (clinical), ICD-10 (diagnoses), ATC (drugs). "Blood pressure" is always code 85354-9.

3One REST API everywhere

GET /Observation?patient=ravi&code=85354-9 works identically in Visakhapatnam, Madrid, or Boston.

4Profiles for local rules

Each project tightens the standard for its use case ("BP must include systolic + diastolic") without breaking compatibility.
